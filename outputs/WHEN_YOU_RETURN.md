# Read this when you return

The software foundation is built and tested. It has 4 ASL choices, 4 Emirati Sign Language choices, improved hand tracking, webcam capture, text, speech, confidence rejection, correction buttons, a separate final-test report and an optional computer-control tab.

For the full beginner explanation, read `docs/FULL_BEGINNER_GUIDE.md`.

It is not trained yet. Codex cannot honestly create that missing human data.

## Your next actions

1. Start the app with `start_signbridge.bat`.
2. Ask fluent signers to check all 8 linked sign forms.
3. If you are the demonstrator, record 20 to 30 varied attempts per class. Add other training people if available.
4. Train both models.
5. Test at least one completely new person in **Final test**; two or three is better.
6. Remove any sign that misses the test targets.

Do not call it a full translator. For the event, call it an **8-sign bilingual isolated-sign prototype**. The computer-control gestures are a separate generic-gesture experiment.
